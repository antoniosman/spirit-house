# Spirit House

[Παίξε το Spirit House](https://antoniosman.github.io/spirit-house/)

Ένα κινηματογραφικό παιχνίδι κοινωνικής στρατηγικής που τρέχει ως installable PWA.

Δημιούργησε cast από τους 22 Spirit χαρακτήρες ή πρόσθεσε δικούς σου παίκτες με εικόνα και όνομα. Ρύθμισε στρατηγική, κοινωνικότητα, αγωνιστική ικανότητα, σχέσεις και συμμαχίες και παρακολούθησε τη σεζόν να εξελίσσεται μέχρι τον τελικό.

## Χαρακτηριστικά

- 4–24 παίκτες ανά σεζόν
- Custom χαρακτήρες με τοπικό image upload
- Φιλίες, αντιπαλότητες και συμμαχίες
- Διαδοχικά επεισόδια με αγωνίσματα, υποψηφιότητες, veto και αποχωρήσεις
- Ανατροπές με τρεις υποψηφίους, μαγική Έκλειψη, Θυσία, διπλή αποχώρηση και Πύλη Επιστροφής
- Cinematic reveals, προαιρετικός ήχος και grayscale αποχωρησάντων
- Αυτόματη αποθήκευση και offline λειτουργία

## Τοπική εκτέλεση

```bash
python -m http.server 4173 --directory dist
```

Άνοιξε το `http://localhost:4173`.

## Τεχνολογία

Vanilla HTML, CSS και JavaScript. Δεν απαιτεί build step ή εξωτερικό backend.
